## Task 4.2: Build Separated UI Components & Codex Affinity Graph
- **State Management**: `src/context/WorldContext.tsx` — useReducer-based context with actions:
  - SELECT_WORLD, SET_PLAY_STATE, APPEND_CHAPTER, SET_CHARACTERS
  - SET_CHECKPOINTS, SET_CARDS, SET_STYLE_CARD, SET_LOCATION_MAP, RESET
  - Custom hook `useWorld()` for consuming components
- **Layout Components**:
  - `Sidebar.tsx`: Backend URL input, health indicator, world creation form, seed demo button, collapsible
  - `MainPanel.tsx`: World header (display name, genre, chapter count), placeholder/error states
  - `WorldSelector.tsx`: Dropdown with world list, delete, active state highlighting
- **Story Components**:
  - `PlayView.tsx`: Mode tabs (Story/Codex/Map), segment control (Story/Status/Debug)
  - `ChapterFeed.tsx`: Scrollable feed of polaroid-style chapter cards, loading spinner, suggested actions chips, summary toggle
  - `InputBar.tsx`: Multi-line textarea, send on Enter, regenerate button, disabled state
- **Status Components**:
  - `PlayStatusSidebar.tsx`: Character info card (name, location, age, realm/exp, traits), story progress, karma display, status effects
  - `InventoryGrid.tsx`: CSS grid layout for inventory items with hover effect
  - `SkillsPanel.tsx`: Gradient-styled skill list
- **Codex**:
  - `CodexView.tsx`: Two-panel layout (card list + affinity graph), locked/unlocked cards, export story button
  - `AffinityGraph.tsx`: React Flow with:
    - Character nodes distributed in circle layout with gradient styling
    - Relationship edges with arrow markers (solid for defined, dashed for undefined)
    - Edge labels showing relationship description
    - Background grid, Controls, MiniMap
    - `buildRelationshipMap()` utility to extract relationships from characters
- **Common**:
  - `Toast.tsx`: ToastProvider + useToast hook, animate in, error/celebrate variants
  - `Modal.tsx`: Backdrop with Escape key handling, header/body/footer slots
- **Styles**: `src/styles/global.css` — full "Starlight Scrapbook" theme (periwinkle/sakura/gold palette, rounded everything, custom scrollbar)

## Task 4.3: Interactive Location Map Tab Component
- `LocationMap.tsx`: Full SVG-based interactive map with:
  - Normalized coordinates (0-100), auto-scaled to container dimensions
  - Dark gradient background with grid pattern
  - Connection lines between locations (styled solid for unlocked, dashed for locked)
  - Node circles with color coding (gold = starting, periwinkle = unlocked, dim = locked)
  - Fog of War: locked nodes render with fog filter overlay + 🔒 icon + "???" name
  - Character location indicators (small pink dots grouped under node)
  - Tooltip on hover showing name, description, unlock requirements
  - Lock condition evaluation (EXP check, realm check, starting location always unlocked)
  - SVG glow filter for starting node
  - Legend overlay (Unlocked/Locked/Start)
- `MapTab.tsx`: Wrapper with header showing protagonist realm/EXP, loads map data, empty state for worlds without maps
